# Changelog

## 1.0.3.1 — 2026-11-09

Fix activation and deactivation handling of the Apache configuration file. Request a five-minute PHP execution limit at runtime when permitted, without reducing higher or unlimited limits. Server and proxy limits may still apply.

Tested on WordPress 6.8.3 with PHP 8.3.28 and WordPress 7.1.4 with PHP 8.4.27.
